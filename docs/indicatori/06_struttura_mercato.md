# Struttura del mercato e price action

| Indicatore/pattern | Calcolo sintetico | Parametri principali |
|---|---|---|
| Donchian breakout | Rottura del massimo/minimo rolling | periodo n |
| Highest/Lowest | Estremo mobile | periodo n |
| Price channel | Bande da massimi/minimi | periodo n |
| Range expansion | Range corrente rispetto a media/percentile | finestra, soglia |
| Inside bar | High e low contenuti nella barra precedente | nessuno |
| Outside bar | High superiore e low inferiore alla barra precedente | nessuno |
| Engulfing | Corpo corrente ingloba il precedente | definizione corpo |
| Pin bar | Corpo piccolo e ombra dominante | rapporti soglia |
| Doji | Corpo/range sotto una soglia | soglia |
| Hammer/Shooting Star | Forma candela e posizione nel range | rapporti ombre/corpo |
| Double top/bottom | Due estremi simili separati da ritracciamento | tolleranza, distanza |
| Head and shoulders | Tre estremi con testa centrale maggiore | tolleranze, neckline |
| Triangle/Wedge | Trendline convergenti | pivot, tolleranza |
| Flag/Pennant | Impulso seguito da consolidamento | lookback, breakout |
| ZigZag | Estremi filtrati da variazione minima | percentuale o ATR |
| BOS | Rottura dell'ultimo swing | swing lookback |
| CHOCH | Rottura contraria della struttura | swing lookback |
| HH/HL/LH/LL | Confronto tra swing successivi | metodo swing |
