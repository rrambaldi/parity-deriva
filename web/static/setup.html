setup

1 · setup code

The code is in the server's log: run docker compose logs parity and look for the line "parity-deriva setup code". On a PC, docker/pc.ps1 opens this page with the code already in.

start from a profile

Optional. A profile fills in the answers below. It never holds a secret: passwords, tokens and certificates are asked again.

2 · who may open the pages

The proxy in front (Caddy or nginx) checks the certificate and tells this server who it is.

Each provider needs an app of yours, made on its site, with the callback address below.

An address, a whole domain (@example.com), or a GitHub user (github:login).

Anyone who can reach the port is in. Use it on your own PC, where the port is on 127.0.0.1 only.

This page came through a proxy, so the server can be reached from outside: no sign-in is not allowed here.

3 · what this server does

Real money: every live session on this server places real orders. No page can change this later; only a new setup can.

4 · the other servers

This server is the Archive: the others connect to it, each with a token made on its settings page (AI assistants, new program token).

This server is not the Archive: it connects to the one already running, and takes from it the candles, the calendar, the spread set and, for a Test, the strategies and indicators.

On the Archive: settings, AI assistants, new program token.

My own files: put the CSV exports in the import folder (/data/import), or upload them on the settings page. A broker's API needs the broker's keys in the server's .env.

5 · finish

The answers are saved and the server starts again with them.

Your certificate: import it in the browser, then open the app.
