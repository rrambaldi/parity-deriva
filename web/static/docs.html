where it goes

A strategy is one Python file with exactly one class. It reaches the service two ways: an AI assistant submits it over MCP, or you import the file on the settings page (strategy files, import as drafts). Either way it is a draft: backtested only in a sandbox with a ceiling on memory and time, never offered to a live session. It becomes a strategy like the built-in ones - simulations, sets, live sessions - once you enable it on the settings page, after reading its code.

an example

A whole strategy: a fast EMA crossing a slow one, a stop some ATR from the close, a target in R. It is checked with every test run, so it is one the service takes as it is.

"""
EMA-CROSS-DEMO: the example of the docs page. A fast EMA crossing a slow one,
a stop some ATR from the close and a target in R.
"""

from parity_deriva.lib.streaming import Cross, Series
from parity_deriva.strategy.H4 import H4


class EmaCross(H4):
	TAG = 'EMA-CROSS-DEMO'
	INSTRUMENT = 'EUR_USD'
	GRANULARITY = 'H1'
	DESCRIPTION = (
		"A fast EMA crossing a slow one. SIGNAL: long on the bar the fast EMA "
		"closes over the slow one, short on the bar it closes under. STOP: "
		"atrStop ATR from the close. TARGET: reward times the stop distance.")

	FAST = 20
	SLOW = 50
	INDICATORS = ({'kind': 'ema', 'period': FAST}, {'kind': 'ema', 'period': SLOW})
	PARAM_HELP = {
		'fast': 'period of the fast EMA, in bars',
		'slow': 'period of the slow EMA, in bars',
		'atrStop': 'stop distance from the close, in ATR',
		'reward': 'target as a multiple of the stop (R)',
	}

	def setup(self, args):
		self._set(args, 'fast', self.FAST)
		self._set(args, 'slow', self.SLOW)
		self._set(args, 'atrStop', 2.0)
		self._set(args, 'reward', 2.0)

	def series(self):
		state = Series(ema=(self.fast, self.slow), atr=self.atrPeriod)
		state.cross = Cross()
		return state

	def signal(self, state, candle):
		fast, slow, atr = state.ema(self.fast), state.ema(self.slow), state.atr()
		side = state.cross.add(None if fast is None or slow is None else fast - slow)
		if not side or not atr:
			return None
		stop = candle.mid['c'] - side * self.atrStop * atr
		return side, stop, self.levels(candle, side, stop, self.reward)

the class

A subclass of parity_deriva.strategy.H4.H4 - or of a strategy already here, when yours is close to it: a base to extend, not a file to copy. On the class:

TAG
its name. The one it is saved under replaces it, so it is only a label for the file.
INSTRUMENT, GRANULARITY
what it is meant for, e.g. 'EUR_USD' and 'H1': what the simulate page selects when it is picked.
DESCRIPTION
its rules in plain words - signal, entry, stop, target, exit - for the person who reads the code before enabling it.
PARAM_HELP
{'name': 'meaning'} for every parameter: the line under its field on the simulate page.
INDICATORS
the curves the chart draws over its runs: {'kind': 'sma' | 'ema' | 'bollinger' | 'atr', 'period': n} (a Bollinger also takes 'deviations').
ATR_PERIOD
14 unless changed: the period of the ATR the base keeps, as self.atrPeriod.

the methods

setup(self, args)
reads each number that sets a rule with self._set(args, 'name', default): it becomes self.name, a parameter the simulate page shows a field for and a backtest can be given.
series(self)
the reading state of one instrument, made once for each: usually a Series declaring what it reads - Series(ema=(20, 50), sma=(), stdev=(), atr=14, rsi=14, volume=20). Anything else the strategy keeps goes on it too.
signal(self, state, candle)
called on every closed bar, after the state has taken it. Returns None, or (side, stop, target): side 1 for a long, -1 for a short, stop and target as prices.
feed(self, state, candle)
advances the state; by default state.add(candle). Written again when the state is more than one series - weeks built with Weekly, say - calling the base's first.
self.levels(candle, side, stop, ratio)
a target ratio times the stop distance, on the right side.

the candle

candle.time is the bar's open, a naive UTC datetime. candle.mid, candle.bid and candle.ask are dicts with 'o', 'h', 'l', 'c'; candle.volume and candle.instrument are there too. The bar has closed when it arrives, so nothing read from it is a look ahead - and nothing in the helpers reads a bar that has not arrived.

what a signal becomes

A market order on the next bar's open, with the stop and the target as a bracket, sized from the page's risk and the stop distance. One position at a time. The spread is in it: a long opens on the ask, a short on the bid.

a richer base: M15

parity_deriva.strategy.M15.M15 extends H4 for strategies that manage their trade, on any granularity (set GRANULARITY). Its signal() returns a dict - {'side', 'stop', 'target'}, an optional 'key' naming the move for the attempts, and anything else kept with the trade - and exit(state, candle, held) returns EARLY_EXIT to close the open trade on this bar. On the class: a stop entry at the bar's far end (STOP_ENTRY, ENTRY_BARS), and the refusals MIN_REWARD, MAX_ATTEMPTS, DAILY_STOP_R, MAX_BAR_ATR, TIME_STOP_BARS - each one in the helpers below.

versions

Nothing is ever replaced. The first strategy saved under a name is its version 1, MY-EMA 1; every one saved under that name after it is the next version, and the ones before stay as they were. That code is its name everywhere - the page, the runs, a backtest. The service ends the file with a PARITY_DERIVA line saying which version it is and the server it was written on: leave it, it is written again on every save.
