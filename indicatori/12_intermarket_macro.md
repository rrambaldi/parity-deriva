# Intermarket e macro

| Indicatore | Calcolo sintetico | Parametri principali |
|---|---|---|
| Relative strength | Rendimento asset / benchmark o ratio prezzi | benchmark, finestra |
| Beta | Covarianza asset-benchmark / varianza benchmark | finestra |
| Advance-decline line | A/D cumulati | universo, data iniziale |
| Advance-decline ratio | Titoli in rialzo / titoli in ribasso | universo, periodo |
| McClellan oscillator | EMA veloce A/D - EMA lenta A/D | periodi |
| New highs/lows | Conteggio nuovi massimi e minimi | lookback |
| % sopra SMA | Titoli sopra la media / universo | SMA, universo |
| TRIN | (advancing issues/declining issues)/(advancing volume/declining volume) | universo |
| Put/call ratio | Put open interest o volume / call | mercato, finestra |
| VIX/volatility index | Indice di volatilità implicita | scadenza/metodologia |
| Credit spread | Rendimento credito - rendimento risk-free | scadenze, strumenti |
| Yield spread | Differenza tra rendimenti/scadenze | maturità |
| Dollar index | Indice ponderato di valute contro USD | paniere |
| Copper/Gold ratio | Prezzo rame / prezzo oro | strumenti, frequenza |
| Realized volatility | Deviazione standard dei rendimenti realizzati | finestra, annualizzazione |
| Economic surprise | Scarti standardizzati tra dati pubblicati e attese | finestra, database |
