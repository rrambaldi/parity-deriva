# Indicatori specifici per criptovalute

| Indicatore | Calcolo sintetico | Parametri principali |
|---|---|---|
| Funding rate | Tasso periodico tra posizioni perpetue long/short | exchange, intervallo |
| Open interest | Contratti derivati aperti | mercato, aggregazione |
| Futures basis | (futures/spot-1) annualizzato | scadenza, giorni |
| Long/short ratio | Posizioni o account long / short | exchange, finestra |
| Liquidations | Valore liquidato per direzione | finestra |
| Exchange netflow | Inflow - outflow verso exchange | asset, finestra |
| Exchange reserves | Saldo custodito dagli exchange | exchange, asset |
| Active addresses | Indirizzi attivi nel periodo | periodo, chain |
| NVT | Market cap / volume transazioni | periodo |
| MVRV | Market value / realized value | asset, periodo |
| SOPR | Valore venduto / valore acquistato degli output spesi | periodo |
| Dormancy | Coin-days destroyed / volume trasferito | periodo |
| Hash rate | Potenza computazionale stimata | finestra |
| Mining difficulty | Difficoltà di mining della rete | chain |
| Stablecoin supply | Offerta circolante delle stablecoin | asset, chain |
| Whale transactions | Conteggio/valore transazioni oltre soglia | soglia, finestra |
| Token unlocks | Token sbloccati rispetto all'offerta | calendario, periodo |
| Gas fees | Commissioni medie o percentili | chain, finestra |
| DEX liquidity | Liquidità nei pool, TVL e profondità | pool, chain |
| Staking ratio | Token in staking / supply circolante | chain, periodo |
