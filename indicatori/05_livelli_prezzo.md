# Supporti, resistenze e livelli di prezzo

| Indicatore | Calcolo sintetico | Parametri principali |
|---|---|---|
| Pivot classici | P=(H+L+C)/3; livelli derivati da P e range | H,L,C precedenti |
| Fibonacci pivot | Pivot e livelli proporzionali al range | coefficienti Fibonacci |
| Camarilla | Livelli attorno alla chiusura proporzionali al range | coefficienti |
| Woodie | Pivot con peso maggiore alla chiusura | H,L,C precedenti |
| DeMark | X dipende da relazione open/close; livelli da X | OHLC |
| High/Low rolling | Massimo/minimo degli ultimi n periodi | periodo n |
| Opening Range | Massimo/minimo della prima finestra temporale | durata finestra |
| Fibonacci retracement | Estremi ± percentuali del movimento | estremi, livelli |
| Fibonacci extension | Estensione oltre l'estremo con rapporti | estremi, coefficienti |
| Frattali | Massimo/minimo con barre più basse/alte ai lati | barre laterali |
| Swing high/low | Estremo locale confermato da barre successive | lookback, conferma |
| Psychological levels | Arrotondamento a multipli di una soglia | step prezzo |
| Volume Profile levels | POC, VAH, VAL da distribuzione volume-prezzo | bin, value area |
| FVG | Gap tra range di candele non sovrapposti | definizione gap |
| Supply/Demand zone | Zona derivata da impulso e base | lookback, soglie |
| Order Block | Ultima candela contraria prima di impulso definito | criteri impulso |
