# Indicatori ciclici e temporali

| Indicatore | Calcolo sintetico | Parametri principali |
|---|---|---|
| Time-of-day | Media/ritorno condizionato all'orario | bucket temporali |
| Day-of-week | Statistiche condizionate al giorno | giorni, finestra |
| Seasonality | Media per mese/stagione o indice ciclico | periodo, normalizzazione |
| Hilbert Transform | Componenti analitiche di fase e ciclo | smoothing |
| MESA | Filtri adattivi basati sul ciclo dominante | periodo minimo/massimo |
| Ehlers filters | Filtri digitali passa-basso/roofing | periodi, coefficienti |
| Dominant Cycle | Stima della periodicità prevalente | finestra, metodo |
| Sine Wave | Sinusoide di fase stimata | periodo, fase |
| STC | Ciclo e MACD con trasformazione stocastica | periodi MACD/ciclo |
| Expiry effect | Rendimento condizionato a scadenze | calendario, finestra |
